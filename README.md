# Bugfixer Extend

프로젝트별 작업 보드에서 에이전트에게 일을 전달하고 실행·검증 결과를 확인하는 VS Code 기반 작업 워크스페이스를 기획 중입니다.

앱 기반은 Whiteboard의 Code OSS 기능을 활용하는 방식과 Bugfixer 개념을 바탕으로 새 앱을 만드는 방식을 다시 비교 중입니다. 어느 쪽이든 프로젝트별 작업 보드와 에이전트 실행을 범용 기능으로 새로 설계하며, 비공개 Bugfixer 저장소의 파일·데이터를 그대로 복사하지 않습니다. 프로젝트별 작업 데이터와 Whiteboard 리뷰 데이터의 연결 방식은 설계 중입니다.

화면은 posco-mds의 라이트·다크 테마 원칙을 참고해, 프로젝트 대시보드와 간결한 탭 중심으로 구성할 예정입니다.

각 프로젝트의 컨벤션을 작업 실행에 주입합니다. Slack·Notion·웹사이트 자료 가져오기를 기본 제공하고, 사용자가 같은 계약을 따르는 커넥터를 설치해 출처가 보존된 자료를 작업·근거에 연결하는 것이 목표입니다. 이 범용 기능은 새로 구현할 대상입니다.

Mobius의 계정 전환과 ego-lite의 브라우저 E2E도 이 워크스페이스에서 연결할 대상입니다.

첫 제품은 macOS에서 사용하고, Windows x86 지원은 이후 단계에서 진행합니다.

현재 기능과 새 제품에서 구현할 범위는 [발견 기록](docs/discovery.md)에 정리했습니다.
