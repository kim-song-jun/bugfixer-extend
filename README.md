# Bugfixer Extend

프로젝트별 작업 보드에서 에이전트에게 일을 전달하고 실행·검증 결과를 확인하는 VS Code 기반 작업 워크스페이스를 기획 중입니다.

선택한 기반은 Whiteboard의 Code OSS 데스크톱 앱입니다. Bugfixer의 화면·API·실행 코드를 앱 내부 모듈로 병합하는 방향으로 설계를 진행합니다. 프로젝트별 작업 데이터와 Bugfixer·Whiteboard의 기존 데이터 연결 방식은 설계 중입니다.

Mobius의 계정 전환과 ego-lite의 브라우저 E2E도 이 워크스페이스에서 연결할 대상입니다.

첫 제품은 macOS에서 사용하고, Windows x86 지원은 이후 단계에서 진행합니다.
