# Bugfixer Extend

프로젝트별 작업 보드에서 에이전트에게 일을 전달하고 실행·검증 결과를 확인하는 VS Code 기반 작업 워크스페이스를 기획 중입니다.

선택한 기반은 Whiteboard의 Code OSS 데스크톱 앱입니다. 직접 만든 Bugfixer의 작업 보드·에이전트 실행 개념을 참고하되, 새 제품의 프로젝트 모델에 맞는 범용 모듈을 앱 내부에 새로 설계합니다. 비공개 Bugfixer 저장소의 파일·데이터를 그대로 복사하지 않습니다. 프로젝트별 작업 데이터와 Whiteboard 리뷰 데이터의 연결 방식은 설계 중입니다.

각 프로젝트의 컨벤션을 작업 실행에 주입하고, 사용자가 확장 기능으로 Slack·Notion·웹사이트 자료를 가져와 출처를 보존한 작업·근거에 연결하는 것도 목표입니다. 기존 제품에 이 범용 확장 기능이 모두 구현돼 있다는 뜻은 아닙니다.

Mobius의 계정 전환과 ego-lite의 브라우저 E2E도 이 워크스페이스에서 연결할 대상입니다.

첫 제품은 macOS에서 사용하고, Windows x86 지원은 이후 단계에서 진행합니다.
